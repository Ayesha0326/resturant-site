# Restaurant Website

A modern and responsive restaurant website built using HTML, CSS, and JavaScript. The website provides an attractive interface to explore food items, view galleries, and make reservations.

## Features

- Responsive restaurant website design
- Attractive homepage and hero section
- Food gallery
- About section
- Customer reviews section
- Reservation section
- Interactive navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
resturant-site/
├── index.html
├── style.css
├── script.js
└── Images/
```

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Ayesha0326/resturant-site.git
   ```

2. Open the project folder.
3. Run `index.html` in your browser.
